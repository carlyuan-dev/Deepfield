# 0.1.2 版本收口（2026-10-21）

应用版本 0.1.2，公司调研包 4.0.0；代码基线为 `92b0ce2` 加本批验收修改，本批增量整理为一个提交，既有发布历史保留。用户已完成本批手测验收并授权同步 develop → staging → main。这是内部稳定检查点；当前本地包未完成公开发行所需的正式签名与公证。

## 本轮内容

- 相对 0.1.1，完成 Config、Model、Search、Tools、Agent、Database、Usage、Errors 八域的 Base 抽取及实际消费接线。主 Chat 与公司调研复用通用底座，公司仓储由能力包管理；依赖与兼容边界见 [Base 总览](../base/base.overview.设计文档.md)和 [Base 抽取设计](../base/base.extraction.设计文档.md)。
- Chat 确认关联真实业务表单与页面，修改草稿、确认、回执和后续导航保持同一操作关联；明确的自然语言批准可确认当前已展示操作，任务范围批准沿用冻结边界。人工推进后拒绝旧轮次写入与执行，恢复时保留真实回执；中断和模型故障提供可继续处理的状态。左侧交互卡与完成回执保持简短，具体授权、取消与恢复契约见 [Chat 人机交互](../chat/chat.interaction.设计文档.md)。
- 公司调研从 20 个独立模块中一次选择 1–5 个，共用单公司、批量和 Chat 表单。调研进行中可查看、切换和导出历史报告，进度与取消仍指向当前任务，人工选择历史后刷新不抢回。报告输入、历史兼容与重试边界见 [公司调研设计](../capabilities/company-research.设计文档.md)。

## 验证范围与限制

本批用户手测已通过，覆盖当前交互与公司调研使用体验。最终类型检查与全套 Vitest 通过：290 个文件、2624 项通过、2 项跳过；差异检查通过。本轮收口检查未追加真实 LLM／Search 调用，复用既有业务旅程证据；已有自动回归、限定真实链路和历史数据兼容证据按各正式设计保留，其范围不因本次版本收口而扩大。

桌面构建与 arm64 本地应用打包通过；应用元数据及包内版本均核对为 0.1.2，执行文件架构为 arm64，内置公司调研包与已安装版本内容一致。

用户手测通过不等于所有入口、Provider、模型及完整调研路径均已验证，也不证明报告事实正确或质量全面达标。研究结果仍需核验来源、时点和表述，不能直接视为可发布稿。现有数据迁移、旧包兼容与真实调用限制沿用上述正式设计。
