# 0.1.4 版本收口（2026-11-06）

应用版本 0.1.4，公司调研包保持 4.0.1。基于 0.1.3 稳定版交付 Memory 与 Compact；用户已完成本批验收，以 `v0.1.4` 标签定位正式发布源码。

## 本轮内容

- Base.Memory 提供范围隔离、来源与版本、检索、修订、删除和有界提炼；Capability 可通过可选 `memory.v1` 使用本包范围内的记忆。
- Chat 支持明确记住、修改与遗忘，以及新交互的后台学习。每轮按当前有效记录构造长期记忆摘要，设置中可查看、修改、删除和停用记忆。
- Chat Compact 复用 Pi 的摘要与消息切分机制，支持 `/compact`、接近上下文预算时自动压缩及重启续接。原始聊天记录保留，长期记忆与会话摘要分别管理。
- 修复已完成的超长旧消息挤占压缩尾部导致回复失败，以及新对话标题更新事件未被侧栏接收的问题。
- 修复 Qwen 普通调用未明确关闭思考时空正文的兼容问题；自动端测默认隐藏启动。

完整机制见 [Base.Memory](../base/base.memory.设计文档.md)、[Chat Memory](../chat/chat.memory.设计文档.md) 和 [Chat Compact](../chat/chat.compact.设计文档.md)。

## 验证与交付

Memory／Compact 联合真实验收覆盖明确记忆、后台学习、跨会话改写召回、修改、停用、删除、手动与自动压缩、重启续接及工具调用。实际使用当前 Qwen 配置，共 28 次 LLM 请求、0 次 Search；发现的压缩尾部与侧栏标题问题均修复并重验。测试数据已清理，原有记忆、对话与设置已复核。

从本批暂存内容导出的独立发布目录完成类型检查、构建与默认测试：303 个测试文件通过，2650 项通过、2 项跳过。侧栏测试的加载等待时序已修正后复验。真实效果证据对应上述模型与场景，不代表所有 Provider 的效果。最终交付为可直接打开的 Apple Silicon `.app`；构建未正式签名与公证。

记忆、修订和压缩 checkpoint 保存在本机数据库；模型提炼与压缩通过现有 Usage 计量。删除记忆保留原始对话。降级前应保护用户数据，版本标签不保证新数据可由旧版本完整使用。
