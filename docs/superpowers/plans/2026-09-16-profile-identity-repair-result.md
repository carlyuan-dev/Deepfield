# 公司身份确认与一次格式纠正：交付记录

## 本轮变更

- 公司资料补全综合名称、研究主题和本轮证据选择相关业务主体；不能仅因存在母子公司或历史主体便返回歧义，也不能混用其事实。
- 真正无法确认时，公司行提供“确认主体”；弹窗显示原因，接受精确主体名称与可选 HTTP(S) 官网。
- 主体提示原子保存后，同一公司进入补全队列。提示仅代表用户意图，不直接写入已核实资料。后续技术失败仍保留最新提示并提供“修改主体”。
- “身份待确认”位于公司名右侧；操作按钮在分栏下保持正常布局。
- 首次 JSON 解析或 Schema 失败可进行一次工具关闭的格式纠正。复用同一 LLM 配置和证据，随后执行同一严格来源校验；无搜索证据、语义证据错误不触发纠正，第二次无效不继续循环。
- 格式错误使用 EXTERNAL.INVALID_RESPONSE（llm），界面显示“结果格式错误，请重试”；与搜索失败区分。
- 数据库新增可空主体提示列（migration 17），兼容既有资料。
