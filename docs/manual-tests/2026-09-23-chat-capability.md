# Chat 调用 Capability：第三阶段手测

前两阶段已验收；本清单用于第三阶段用户验收，不代表真实模型与 Electron 交互已自动测过。

## 先读取已有资料，不创建新调研

1. 启用公司调研能力并重启。新建 Chat，可关闭联网，发送：**列出已有研究主题，再列出手机主题下的公司。** 应按需调用能力接口，不要求先打开能力页面。
2. 发送：**读取荣耀最新的已有调研报告，总结主要结论和依据，不要重新调研。** 应读取原有报告；如结构化失败，应如实说明而非说整份报告不存在。不会创建新调研记录。
3. 发送：**打开这份报告。** 应定位到对应公司及报告版本。如果页面有未保存输入，应先阻拦或要求处理输入，不覆盖人工编辑。

## 一次确认、队列与结果分析

4. 指定已有公司及研究方向、重点范围、绝对截止日期，请 Chat 准备调研。准备/打开草稿本身不执行调研；需要真实点击确认后才进入已有统一队列。确认参数应与实际执行一致。
5. 提交后切换对话再回来，任务卡保留并更新状态。询问“刚才的任务进度如何”，应查询同一任务。停止当前 Chat 回答不应偷偷取消后台调研；明确要求“取消刚才的调研任务”才取消。
6. 勾选“完成后分析”后，任务完成应在原会话空闲时流式分析已有产物；未勾选则仅更新任务状态。切到其他会话时不插入回复、不抢页面；返回原会话后可继续。新消息优先于待启动分析。

## 启用范围与回归

7. 在设置中取消公司调研勾选但不重启，本次启动的能力仍可用；重启后不再提供该能力的调用工具。历史消息仍保留，不能据此宣称能力仍启用。
8. 普通 Chat 联网/非联网、公司页面手动调研与 Word 导出仍按原方式工作。

自动验证只使用临时目录、测试数据库与 Fake Worker。独立 `record-lookup` 模板不安装到真实用户目录。真实调研将产生正常 LLM/Search 用量，由用户手测时自行决定是否执行。
