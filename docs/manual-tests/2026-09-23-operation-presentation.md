# Chat 操作提示与页面联动手测

状态：已打包，待用户手测。公司调研包 2.1.2；测试应用：`release/mac-arm64/Deepfield.app`。只需使用临时测试主题，不要用重要资料测试删除。

1. 对 Chat 说“新建一个研究主题：交互测试”。右侧应自动出现填写后的预览，尚未创建真实主题；确认提示位于本轮 Agent 回复下方，而非输入框上方固定区域；没有“完成后分析”勾选框。
2. 点击取消：不得创建主题，同一轮保留已取消状态。重新发起并确认：右侧出现新主题，原位置显示真实完成结果，入口可再次打开对应页面。
3. 继续聊其他内容并滚动历史：前一轮的提示留在前一轮，不能重复出现在新回复下方。切换会话再返回，已完成状态仍能看懂。
4. 如需实际调研：发起一家公司调研，确认后右侧显示真实排队/研究阶段；提示在原消息处更新，不随每次进度反复跳转。点击“查看”仍可回到对应页面。
5. 任务运行时切到另一会话或手动查看其他内容，原任务完成不应抢走当前页面。右侧有未保存编辑时，自动联动不得覆盖编辑；操作结果不因页面打不开而虚报失败。
6. 若有未提供可选呈现信息的 Capability：其正常调用和结果读取不变，不产生推测业务卡片/自动跳转；必要的安全确认仍保留。

自动联动展示真实参数、状态与结果，不模拟逐字输入或鼠标点击。没提供可选呈现的包仍可被主 Agent 调用。

补充回归：打开临时公司的报告后，通过 Chat 删除该测试报告并确认，同一公司页面应刷新，不再显示已删除的报告。调研草稿保留手动查看入口，不自动打开编辑器；避免未保存编辑保护阻挡后续提交页面。
