# Chat 任务连续执行与公司补全手测

状态：开发、独立复核、类型检查及生产构建完成，macOS arm64 测试包已替换至 release/mac-arm64/Deepfield.app，实际加载的能力包已同步为 2.4.0。请使用测试主题，删除测试不要选择真实业务资料。

验证范围：本地定向功能测试，无真实模型/Search调用。真实模型语言遵从和自然语言任务规划仍需本轮手测；不会额外调用模型翻译答案。额外检查遇到一条既有迁移版本断言仍期待29（当前31），未改动与本轮无关的迁移逻辑。

## 1. 中文与完成后不重复提案

- 新建中文对话，请求创建“固态电池测试”主题、搜索代表公司并导入。
- 观察工具前说明、确认提示与最终回答均为中文（公司英文名/链接可保留）。
- 如经过识别候选，快速在右侧确认导入；完成后不应再出现同一名单的重复添加卡。

## 2. 本次任务连续操作

- 示例：`新建“固态电池测试”主题，找几家代表公司并导入。本次任务允许连续执行，不用逐项让我确认。` 检查实际任务范围卡、资源消耗与结束条件，确认一次后继续。
- 这里的一次确认是批准已展示的任务范围，不是把一句“全部同意”保存成无限授权；模型只作口头承诺而没有范围卡时，不应声称已获授权。
- 在批准范围内，后续操作仍联动右侧真实页面与表单，但无需再次逐项确认。
- 新任务/取消/超出范围不能继承授权，重启不自动恢复授权。
- 示例：`从“固态电池测试”移除“测试公司”，然后删除“固态电池测试”主题，本次连续执行。` 授权应准确显示两个删除对象；确认范围后两步连续执行，不能把别的主题/公司纳入。请将示例公司名换成真实的测试条目。
- 普通导入授权不能批准删除，也不能自动发起额外公司调研。

## 3. 补全进度随删除变化

- 在正在补全资料的主题删除一个未完成公司，分母立即减一，分子不变。
- 删除一个本批已完成公司，分子分母立即各减一。
- 最后一个公司移除后，不应留下失真的运行中进度。
- 已完成提示仍显示时删除公司，应清除过期的完成提示，而不是保留错误数量。
- 若公司同时属于另一个主题，另一主题的资料补全不应被取消。

## 4. 未知字段重试

- 公司资料除备注外任一基本字段未知，即使此前补全成功也应出现“重试”。
- 点击后排队补全，运行中不能重复提交；已有人工填写字段与来源不因重试失败而丢失。
- 已确认无别名、无官网、未上市不算未知；仅备注为空不出现重试。
