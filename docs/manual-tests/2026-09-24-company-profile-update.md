# 公司信息更新手测（2.4.1）

此清单供安装 2.4.1 后在可控测试数据中执行；本次交付没有启动应用或调用真实模型、搜索及数据库。

交付状态：测试包已更新至 `release/mac-arm64/Deepfield.app`，实际加载能力已同步为 2.4.1；必要功能测试、类型检查、构建和增量复核通过。资料补全尚未结束时也可发起调研，不再等待补全结束。

1. 新建研究主题并导入一家公司。确认导入后立即能在公司列表打开该公司，自动补全继续进行。若补全失败，导入仍显示成功；列表没有重试、感叹号或失败标签。
2. 在资料待更新、更新中以及更新失败时，打开公司详情并启动单家公司调研；分别在批量调研中选中这些公司。已有调研队列条目仍不可重复选择。
3. 对有未知基本字段的公司，确认详情标题右侧依次显示灰色“部分信息未知，可更新信息”、“更新信息”、“编辑信息”、“删除公司”。备注为空不单独触发未知提示。
4. 对所有基本字段已知的公司，确认“更新信息”仍可点击。点击后按钮显示“更新中…”并禁用；等待期间仍可打开和启动调研。
5. 让更新成功与失败各发生一次。成功后详情显示灰色“信息已更新”；失败后显示灰色“更新未完成，可再次更新信息”。失败后先前手动填写的字段及核实来源仍在，列表无失败提示。
6. 对有歧义主体的失败公司，在详情中使用“确认主体”或“修改主体”，检查主体信息仍可修正。另一主题引用同一公司的资料也应同步更新。
7. 检查资料处理完成提示仅显示处理数量，不把资料更新失败计入导入失败；会员关系保存失败仍应按导入错误提示。

打包行为：能力版本从 2.4.0 升为 2.4.1；兼容的 `companies.retryProfile` action/RPC 名称保留，用户可见名称和说明改为“更新公司信息”。
