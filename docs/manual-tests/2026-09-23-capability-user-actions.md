# Chat 功能说明与公司调研操作手测

状态：2026-09-23 已打包，待用户手测。安装包为 `release/mac-arm64/Deepfield.app`，公司调研包 2.1.1，25 项公开动作，新增包自带用户说明。只测本轮变更，不要求重跑全部旧功能。

## 1. 帮助与回答

- 输入 `/help`：直接显示当前功能目录，不调用模型。
- 检查排版有“工具”“能力”标题，工具使用加粗名称和项目符号；公司调研下展示用途、可取得的结果与少量示例问法，不再罗列内部动作名称。说明由能力包自己的 `docs/help.md` 提供；未写说明的能力只显示名称。
- 分别输入“我们有哪些工具可以用？”、“我们有哪些功能可以调用？”、“我们有什么能力？”和“告诉我，你有哪些交互环境的出入口”。自然问法由模型识别后调用“查看可用功能”，依据与 `/help` 相同的目录回答；不出现接口名、参数名、包版本、权限解释或结尾追问。
- 输入“我们有哪些功能？再帮我新建一个调研主题：测试”。功能介绍不能吞掉具体业务请求，后续操作仍按正常确认流程执行。
- 开关 Chat 联网后再次询问：网页搜索/读取网页随当前开关变化；公司调研是否可见由本次启动加载决定，不因直接搜索关闭而消失。
- 输入“列出手机主题下的公司，读取荣耀最新报告”。结果应使用公司名、中文业务状态与日期，不打印 itemId/runId、ready、direction、revision 等内部值。来源链接、产品型号等真实内容不应被删掉。
- 输入“打开这份报告”。成功只需简短确认；未保存输入被阻拦时说明真实原因，不先说打开成功。

## 2. 无新增调研消耗的管理操作

- “帮我新建一个调研主题：大模型”。应能执行，不再要求用户提供 ID；随后检查主题页面是否可见。
- 让 Chat 查询/编辑该主题的研究范围；测试既有公司资料读取与报告版本切换。
- 对专门的测试主题/报告提出删除：先取消确认，检查未删除；再次请求并确认，检查目标与影响范围正确，Chat 有明确结果。不要用重要资料测试删除。
- 对已有报告导出 Word，选择原始/结构化内容；取消文件保存应显示取消，不应显示导出成功。

## 3. 会产生正常用量的操作（按需手测）

- 向测试主题添加或导入少量公司。确认卡应明确自动补全将调用模型/搜索，参数使用公司名称而非后台 ID；完成后能看到结果并继续对候选操作。
- 测试一个资料补全失败公司的重试或主体确认；使用实际需要修改的公司，留意共享资料影响提示。
- 选择两家公司批量调研，为其中一家设置不同范围。确认后进入原统一队列，任务状态在切换 Chat 后仍可恢复。
- 只取消这次提交的任务，不应取消后来独立加入的其他任务。明确取消整个队列则按整个队列处理。
- 对结构化失败报告要求“只重新整理”，应保留原始报告，不重新联网调研；普通失败重试保存用户新填写的参数。

完成操作后的确认消息应保留在原会话。下一轮询问刚才结果时，模型应能继续操作，不要求用户复制 ID，也不额外自动调用模型解释每次点击。

本轮边界：Chat 可打开主题、公司列表、公司与报告页面；关闭能力、进入设置、切换报告原始/结构化页签仍由界面完成。一次识别超过 20 家公司时会明确提示拆分文本；极大批量参数超过确认卡容量时需分批，不会静默隐藏确认内容。

交付校验：业务动作批次的 40 项关键测试通过；本轮帮助说明的 52 项定向测试、提示修复后的 9 项窄测、类型检查和生产构建通过。安装包 7 个宿主产物与 32 个能力文件逐字节校验通过，包含 `docs/help.md`。已备份并更新本机能力程序，未启动应用、未调用真实 API、未修改业务数据。
