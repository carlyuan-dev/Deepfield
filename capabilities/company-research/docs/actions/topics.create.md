# topics.create

提供行业/主题名称 industry，可选研究范围 researchScope 与备注 notes。待确认时右侧可打开只读预览，预览不会创建主题，也没有第二个提交按钮。用户在聊天中确认后才调用创建服务；成功结果指向新主题的公司列表，并刷新主题列表。

连续任务可先用 propose_actions 准备一次可见范围：固定本动作的完整输入，最多执行一次；后续 companies.add 的 itemId 可绑定本规则成功回执的 data.item.id。只有用户确认该范围后才开始。目标主题不能由搜索文本或模型猜测 ID 替代。后续名单可动态确定，但需在同一范围显式列明添加规则和次数、资料补全资源消耗；额外调研与删除不由创建授权推断。
